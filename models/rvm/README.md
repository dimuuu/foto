# Robust Video Matting model

This directory contains the official `rvm_mobilenetv3_tfjs_int8` TensorFlow.js model from [PeterL1n/RobustVideoMatting](https://github.com/PeterL1n/RobustVideoMatting), release [`v1.0.0`](https://github.com/PeterL1n/RobustVideoMatting/releases/tag/v1.0.0).

The model is used locally in the browser for human portrait matting. Uploaded images are not sent to a server.
